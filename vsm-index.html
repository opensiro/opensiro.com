02 / THE AUTONOMY KEY

Autonomy is a pattern.
Read it function by function.

States describe decision rights and closure inside a reviewed boundary. They are not a single maturity score.

A

Agent-owned

The agent holds the decision right and ready enactment exists in the standard setup.

C

Composable

First-party primitives exist. The builder must compose the agent, authority or feedback loop.

P

Parent-assisted

A parent supplies the function through a binding decision or feedback path that returns to subsequent operation.

—

No supplied path

No material first-party path appears inside the stated review boundary.

?

Unknown

Reviewed primary evidence cannot establish the state. Absence is not inferred.

A(P)

Agent-owned in autonomous mode, with an available parent-assisted path that can bind subsequent operation.

C(P)

Composable first-party primitives, with a parent-assisted path that can bind subsequent operation.
